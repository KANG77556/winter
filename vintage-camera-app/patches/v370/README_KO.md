# 빈티지 컬러 카메라 3.7 인물 베스트샷

## 구현 기능

- 연속 촬영 후보의 일반 사진 품질과 인물 촬영 상태를 함께 분석
- 얼굴 위치, 크기, 화면 가장자리 잘림 안전성, 얼굴 부분 선명도 확인
- 인물 모드에서는 품질 55%와 인물 점수 45%를 결합해 BEST 선택
- 아이·가족 모드에서는 감지 얼굴 수가 많은 후보를 우선 고려
- 자동 모드는 후보 절반 이상에서 얼굴이 검출된 경우에만 인물 기준 적용
- 얼굴 미감지 또는 검출 오류 시 기존 사진 품질 점수로 자동 대체

## 개인정보 처리

얼굴 신원, 이름, 나이, 성별 또는 외모를 분석하거나 저장하지 않습니다. 얼굴 위치와 촬영 선명도 계산은 기기 내부에서만 수행합니다.

## 제한 사항

Android 내장 얼굴 검출은 정면에 가까운 얼굴에서 가장 안정적입니다. 옆얼굴, 가려진 얼굴, 매우 작은 얼굴은 검출되지 않을 수 있습니다. 눈 감김과 웃음 여부는 이번 버전에 포함하지 않았습니다.
