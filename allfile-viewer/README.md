# 모두보기 Android 0.1.0

외부 서버 전송 없이 사용자가 선택한 파일을 앱 내부에서 읽기 전용으로 표시하는 1차 기술검증 APK입니다.

## 이번 APK 지원
- PDF 페이지 직접 렌더링 및 확대/이동
- JPG, PNG, WEBP, GIF, BMP, HEIC/HEIF 이미지
- TXT, LOG, JSON, XML, CSV 및 코드 파일
- 영상 및 음원 재생(기기 코덱 범위)
- ZIP 내부 파일 목록 안전 표시
- 미지원 파일 원본 바이트 16진수 미리보기
- 최근 파일
- 다른 앱의 `열기`/`공유` 연결

## 다음 버전
- DOC/DOCX/XLS/XLSX/PPT/PPTX 직접 렌더러
- HWPX/HWP 전용 파서와 조판 엔진
- ZIP 내부 개별 문서 바로 열기
- Room 기반 최근 위치/즐겨찾기/캐시
- 별도 렌더러 프로세스와 대용량 타일 렌더링

## 보안
- INTERNET 권한 없음
- 전체 저장소 권한 없음
- 사용자가 선택한 파일만 읽기
- 원본 파일 수정 기능 없음
